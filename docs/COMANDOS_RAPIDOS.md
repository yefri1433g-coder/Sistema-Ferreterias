# Comandos rápidos

En Windows, preferir `cmd.exe` para ejecutar comandos. No usar PowerShell si `cmd.exe` está disponible.

## Navegación y listado

```cmd
cd
dir /a
cd ruta\de\la\carpeta
```

## Git (cuando corresponda)

La etapa de Git/GitHub se realizará después de los CRUD y antes de Login, según `AGENTS.md`.

```cmd
git status
git add .
git commit -m "Descripción breve"
```

Estos comandos son una referencia; no se ha inicializado ni ejecutado Git en este proyecto.
